# AI Updated

Static site (GitHub Pages, branch `master`, root) publishing a daily AI digest: ≤2 news + ≤5 papers,
250–350 words each. Live: https://guaaaaa.github.io/AI_Updated/

- **Daily scheduled run → follow `RUNBOOK.md` exactly.** It covers selection rubric, writing rules,
  budgets, and the publish/verify step.
- Layout: `index.html` + `assets/` (front end, no build step) · `data/days/YYYY-MM-DD.json` (digests) ·
  `data/index.json` (generated by `pipeline/build_index.py`) · `data/state/alphaxiv_hot/` (daily Hot-feed
  snapshots used as an attention signal) · `config/` (taxonomy, sources, notable authors/labs, site) ·
  `pipeline/` (Python 3 stdlib + bs4 scripts) · `work/` (git-ignored scratch).
- Time zone: America/New_York. Windows: papers 72h (weekend 7d) by arXiv announcement time; news 72h.
- alphaXiv is used only through its free `get_hot_feed` MCP tool (`pipeline/alphaxiv.py`); the API key is
  injected by the cloud environment's network secret for api.alphaxiv.org — never write keys to the repo.
- Papers are read from arXiv (HTML, PDF fallback), never via alphaXiv's quota-consuming tools.
- Validate before publishing: `python3 pipeline/validate.py`. Never hand-edit `data/index.json`.
